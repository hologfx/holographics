# Holographics

Holographics is a tool for adding live graphics to video. Overlay lower-thirds, broadcast messages, ticker tapes and your own custom widgets on a live video feed, or output Key & Fill signals using a supported application.

Holographics runs as a desktop application on Mac or Windows.

## Stack

Electron desktop app with a Node.js / Express + Socket.io server and a Vue 2 control /
render frontend.

## Installation

```sh
npm install
```

`postinstall` generates the client SDK from the server's service list
(`npm run build:clientsdk`).

### Blackmagic DeckLink output (optional)

Hardware Key & Fill output via Blackmagic DeckLink / UltraStudio requires Blackmagic's
**Desktop Video** software installed on the machine. It provides the DeckLink driver and
the `DeckLinkAPI` framework, which is loaded from the system at runtime — nothing
Blackmagic-owned is committed to this repo or bundled into Holographics builds. Without
Desktop Video the rest of the app runs normally; only the DeckLink output is unavailable.

No extra build steps are needed. The `macadam` dependency vendors the redistributable
DeckLink SDK headers and resolves the framework lazily at runtime, so builds (including
CI) work on machines with no Desktop Video installed.

## Development

```sh
npm run dev:electron   # run the Electron app in development
npm test               # Mocha test suite
```

## Building

We use electron-builder for Windows and macOS:

```sh
npm run build:webpack          # bundle client, server and electron
npm run compile:distributable  # package with electron-builder (-mw)
```

Code signing / notarization is configured for macOS (`electron-builder-notarize`,
hardened runtime). You will need to supply your own signing identity; unsigned local
builds still work.

## Releasing & auto-update

Releases are published to **GitHub Releases** and the app auto-updates from there via
`electron-updater` (configured in the `build.publish` section of `package.json`).

```sh
GH_TOKEN=<your_token> npm run build_and_deploy
```

Changelog helper:

```sh
npm run changelog
```
